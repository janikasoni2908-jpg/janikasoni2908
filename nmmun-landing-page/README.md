A premier, fully responsive landing page designed specifically for **Narsee Monjee Model United Nations (NMMUN 2026)** at **SVKM's NMIMS Shirpur Campus (Mukesh Patel Technology Park)**.

## 🌟 The Shirpur Identity: A Residential Diplomatic Retreat
Unlike standard single-day city hotel conferences, NMMUN Shirpur is a **3-day residential retreat** set within an eco-friendly 400-acre collegiate enclave on the Mumbai-Agra Highway (NH-52) in Dhule district, Maharashtra. Delegates live, dine, caucus, and negotiate on-site around the clock.

